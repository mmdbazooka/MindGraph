# A notebook, with room in the margins

MindGraph uses warm paper, sage ink, serif English headings, and Vazirmatn for Persian. The default theme is light; an existing saved dark preference is respected. The dashboard opens with a writing invitation, followed by paper notes with subtle tape/rotation, a connection garden, and bookmarked notes. Counts live beside the graph, rather than in an analytics-card row.

The landing page uses an illustrated notebook collage, editorial numbered sections, and a personal invitation to write. Dark mode uses warm charcoal and muted paper tones. Mobile stacks the notes; RTL mirrors the layout while note text uses its own writing direction.

Reusable editing, library, settings, and graph surfaces inherit the same ink/paper tokens. The independent `identity.css` layer sits between component styles and Tailwind utilities, so utilities retain predictable priority. No external illustration or font service is needed.
